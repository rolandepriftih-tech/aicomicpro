# AI Comic Pro 界面改造设计方案（参考小云雀故事画布）

**来源**：用户录屏演示（小云雀 xyq.jianying.com 小说创作画布编辑器，88 秒，29 帧逐帧分析）
**目标**：把 AI Comic Pro 的界面改造成"全屏创作画布"模式——顶部工具栏 + 左侧垂直工具栏 + 主画布（节点卡片）+ 底部提示词/参数栏 + 底部操作栏
**技术栈**：保持 Next.js + React Flow（现有画布），只重构布局与交互层
**红线**：不动 AutoDL 生成链路、prompt-skills 润色链路、持久化逻辑；现有 React Flow 拖拽/连线/右键保留

---

## 一、整体布局（5 区 + 悬浮层）

```
┌──────────────────────────────────────────────────────────────┐
│ ① 顶部工具栏：项目名(保存状态) | 风格▾ | 画幅▾ | 积分 | 开会员 | 分享 | 头像 │
├──────┬───────────────────────────────────────────────────┬─────┤
│ ② 左 │                                                    │     │
│ 垂直 │        ③ 主画布（无限画布，节点卡片）               │     │
│ 工具 │    卡片可选中/关联/批量/缩放/多选                   │     │
│ 栏   │    选中时：卡片悬浮工具条 + 底部批量操作条          │     │
├──────┴───────────────────────────────────────────────────┴─────┤
│ ④ 底部创作栏：提示词输入(@引用素材) + 参数行 + 生成按钮(✨+消耗)    │
│ ⑤ 最底部：撤销/重做/AI/网格/对齐 + 缩放控制(- 46% +)             │
└──────────────────────────────────────────────────────────────┘
悬浮层：添加节点面板（点+弹出）、参数调节浮层（点参数弹出滑条）、参考区面板（图生视频）
```

## 二、各区组件与规格

### ① 顶部工具栏
- 左侧：项目名（可编辑）+ **保存状态标签**（"未命名/保存中/已保存"）
- 中间：当前风格下拉（复用 16 种画风）、画幅比例下拉（16:9 / 9:16 / 1:1 / 3:4）
- 右侧：积分/额度（如 ✦60）、"开会员"占位、"分享"、用户头像
- 高度 44-48px，深色底

### ② 左侧垂直工具栏（图标无文字，hover tooltip）
- `+` 添加 → **弹出"添加节点"面板**（见悬浮层）
- `✨` AI 创作
- `📁` 素材库（资源抽屉）
- `?` 帮助
- 宽度约 48px

### ③ 主画布（React Flow）
- 无限画布，浅灰/深色网格底
- 节点 = 卡片（见第三节）
- 支持：拖拽、连线、多选、框选、缩放、切换箭头（卡片多图左右切换）
- 选中态：控制点 + 状态文字（"已选中 0/第1张"）

### ④ 底部创作栏（核心）
- **提示词输入框**：placeholder"描述你想要生成的画面内容，@引用素材"；支持 @ 引用选中素材；右上角刷新图标
- **参数行**（一行紧凑，每个参数可点开浮层调节）：
  - `+`（添加上下文）/ `@`（引用素材）
  - 当前风格标签（可切换）
  - 比例调节（如 ↕️ 2.5，点开滑条）
  - 分辨率（480p/720p/1080p，点开下拉）
  - 时长（视频模式 5s/10s/15s，**点开滑条浮层"视频时长"**）
  - 生成模式（无/图生/多图参考/全参考）
  - 运镜开关
  - 更多(...)
- **生成按钮**：右侧圆形，向上箭头 + 本次消耗（"✨ +260"）；点击生成
- 高度约 96-120px，全宽固定底部

### ⑤ 最底部操作栏
- 撤销 / 重做 / AI / 网格 / 对齐 / 放大镜
- 画布缩放：`-` `46%` `+`
- 右下角：素材/轨道缩略图入口
- 高度约 36px

## 三、节点卡片结构（角色/场景/视频/图片/文本/音频统一）

```
┌─────────────────────────┐
│ 标题：未命名角色      …  │  标题 + 更多(...)
│ ┌─────────────────────┐ │
│ │  内容区：            │ │  无内容：灰色占位 + 上传图标
│ │  占位图 / 预览图     │ │  有内容：图/视频预览
│ │  多图：左右切换箭头  │ │
│ └─────────────────────┘ │
│ [上传] [资产库]          │  卡片主操作（上传本地/从素材库选）
│ 经典模式▾ · 7张 · 状态   │  状态：待生成(橙)/待补充/生成失败(红)/已生成(绿)
└─────────────────────────┘
选中/悬浮时顶部出现工具条：全选 复制 图像分离 裁剪 缩放 更多(...)
```

- **节点类型**（添加节点面板提供）：角色、场景、3D导演台、文本、图片、视频、音频
- **操作按钮**：上传（本地文件）、资产库/用户库（从素材库选）
- **状态标签行**：模式▾ + 张数 + 状态（待生成橙/待补充/生成失败 1/1 红/已生成绿）
- **选中**：边框高亮 + 控制点 + 状态文字 + 顶部悬浮工具条
- **多选**：底部出现批量操作条（抽帧/提高画质/截取/音频分离/裁剪/翻转/智能成片/片段重排/旋转）

## 四、悬浮层与弹层

### 添加节点面板（点左侧 + 或画布空白处弹出）
- 节点类型网格：角色 / 场景 / 3D导演台(new) / 文本 / 图片 / 视频 / 音频
- "添加资源"区：上传 / 从小云雀资产库选择
- 位置：画布右侧或跟随触发点，非模态

### 参数调节浮层（点底部参数行任一项弹出）
- 时长：蓝色滑动条 + 当前值（"10秒"）
- 比例/分辨率：下拉或滑条
- 关闭：点击浮层外或 ×

### 参考区面板（图生视频/多图参考模式）
- 大卡片（横版/竖版）带"上传 / 用户库"
- 用于设定生成视频的视觉参考（对应 ai-comic-pro 的参考图/分镜图选择）

## 五、交互流程（详细状态机）

### 5.1 节点生命周期
```
创建：点 + → 添加节点面板 → 选类型 → 画布出现空白卡片（状态"待补充"）
填充：点卡片 [上传]/[资产库] → 填素材 → 卡片有内容，状态"待生成"（有提示词）
生成：底部输入提示词（可@引用选中素材）→ 配置参数 → 点 ✨生成 →
      卡片状态流转：待生成(橙) → 生成中(转圈/进度) → 已生成(绿，显示预览) / 生成失败(红，"生成失败 1/1")
重试：失败卡片可点"重试"或底部再生成（失败原因提示，如"请选择背景 3次"）
```

### 5.2 生成流程
1. 选中要生成的卡片（可多选）
2. 底部输入框写提示词；@ 引用选中素材（自动带素材引用）
3. 配置参数：风格/比例/分辨率/时长/模式/运镜（点开浮层调节）
4. 点生成按钮（显示本次消耗 ✨+260）
5. 生成中：卡片状态"生成中"（不阻塞其他操作）
6. 结果：成功显示预览（多图卡片带切换箭头）；失败显示"生成失败 1/1" + 原因

### 5.3 选中与批量
```
单击卡片 → 选中（控制点 + "已选中 0/第1张" + 顶部悬浮工具条）
多选/框选 → 底部批量操作条出现（抽帧/提高画质/裁取/裁剪/翻转/智能成片/片段重排/旋转）
取消选择 → 点空白处
```

### 5.4 卡片编辑
- 顶部悬浮工具条：全选 / 复制 / 图像分离 / 裁剪 / 缩放 / 更多(...)
- 卡片切换箭头：多张图/变体左右切换
- 卡片间连线：复用现有连线（角色→分镜→视频 关联）
- 删除：选中后 Delete 键或卡片"删除"（复用现有 handleNodeDelete + onNodesDelete 清理）

### 5.5 画布操作
- 缩放：底部 - / 百分比 / +（或滚轮）
- 撤销/重做：底部操作栏
- 网格/对齐：底部操作栏（辅助对齐）
- 拖拽节点、右键菜单（复用现有）

## 六、视觉风格（基于录屏观察）

- 背景：浅灰底画布（或沿用现有深色主题，二选一保持一致）
- 卡片：圆角矩形（rounded-xl）、浅灰边框/白色底、阴影、hover 微浮起
- 文字：紧凑小字号（10-12px 标签、14px 标题）
- 状态色：橙（待生成）、红（失败）、绿（成功）、蓝（选中）
- 顶部/底部栏：深色底与画布区分；参数按钮浅灰底

## 七、实现建议（给 Claude 的落地指引）

1. **布局重构**：page.tsx 改为 5 区布局；ScriptPanel 的引擎配置收敛进顶部/侧边抽屉（配置与创作分离）
2. **底部创作栏**：新组件 `components/CanvasCommandBar.tsx`（提示词 + 参数 + 生成按钮 + @引用），替代散落入口
3. **卡片改造**：统一 Plan4Canvas 节点视觉（标题+内容区+上传/资产库+状态标签+切换箭头+悬浮工具条）；AssetNode/PanelNode/VideoNode 统一
4. **添加节点面板**：新组件 `components/AddNodePanel.tsx`（节点类型网格 + 添加资源）
5. **参数浮层**：新组件 `components/ParamPopover.tsx`（滑条/下拉，复用现有 video-options 常量）
6. **批量操作条**：复用 handleBatchGenerateImages，多选时显示（抽帧/提高画质等映射到现有能力）
7. **@ 引用素材**：提示词输入框支持 @ 选中节点 → 自动引用素材
8. **生成状态**：节点 data 加 `genStatus`（待补充/待生成/生成中/成功/失败 + 失败原因）驱动卡片状态显示
9. 保持 React Flow 交互（拖拽/连线/右键/onNodesDelete 清理）；**不动 AutoDL 链路、prompt-skills 润色链路、持久化**

## 八、验收

- 5 区布局 + 悬浮层完整，画布占主视觉
- 添加节点面板、参数浮层、参考区可用
- 节点卡片统一结构 + 状态标签 + 切换箭头 + 选中工具条
- 底部创作栏：提示词 + @引用 + 参数 + 生成按钮（触发现有生成链路）
- 生成状态流转：待生成 → 生成中 → 成功/失败（含失败原因与重试）
- 多选批量操作可用
- 现有功能（AutoDL 视频/润色/生图/持久化）无回归
